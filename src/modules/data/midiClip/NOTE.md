# MIDI Clip

Categoria: data · rate: control

## L'idea

Le note di un file .mid lette dalla fase (beat per ciclo): piegare o invertire la fase piega o inverte la clip. Le note restano nella patch.

## Da provare

- Carica una clip e leggila con Ø Bend: il groove respira senza toccare le note.
- Beat per ciclo da 4 a 2: la clip rallenta a metà, e anche le durate.
