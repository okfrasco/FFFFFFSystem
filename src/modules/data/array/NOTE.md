# Array

Categoria: data · rate: control

## L'idea

Una tabella che si registra al volo da qualunque segnale (eventi con valore o valore continuo) e si rilegge con la fase. La tabella è stato: le scene la catturano.

## Da provare

- Markov → Array in registrazione per una battuta, poi Registra a no: la frase si congela e si ripete.
- Registra un LFO lento, rileggi con una fase più veloce.
