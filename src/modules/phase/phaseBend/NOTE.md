# Ø Bend

Categoria: phase · rate: control

## L'idea

Il groove come fase piegata (Bitwig Grid, Autechre): lo stesso pattern suona
accelerando o rallentando dentro la battuta, senza toccare il pattern.

## Da provare

- Transport → Ø Bend → Clock ÷16 → Markov: la melodia corre verso la fine della battuta.
- Pinch sulla fase del beat (Transport.beat): i sedicesimi si stringono sul tempo.
- Un LFO aliasato sulla quantità: ogni battuta una piegatura diversa.
