# Tuning

Categoria: harmony · rate: control

## L'idea

Microtonalità: accordature pronte (giusta, pitagorica, armonici, 19/24/31-TET, Bohlen-Pierce, slendro, pelog) o un file Scala. Le altezze escono frazionarie.

## Da provare

- Tonnetz → Tuning (giusta): le triadi senza battimenti.
- 19-TET su una linea di Pitches: i tasti diventano diciannovesimi d'ottava.
