# Echo

Categoria: transform · rate: control

## L'idea

Echi di eventi invece che di audio: ogni ripetizione è un colpo vero, che si può trasporre e mandare a un altro suono.

## Da provare

- Echo sulle note della melodia con trasponi +7: echi che salgono per quinte.
- Tempo in cicli (fase collegata) 0.1875 = 3/16: echi puntati a tempo.
